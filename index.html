About

I'm a software engineer who likes the unglamorous parts: the query that was doing an N+1, the bundle that was 400 kB too big, the form that nobody could use with a keyboard.

Most of my work sits between the browser and the database — React and TypeScript on one side, Python and Postgres on the other. I care about writing code that the next person can read, and about shipping things that measurably work rather than things that merely demo well.

Outside of work I maintain a couple of small open-source tools, and I write occasionally about performance and developer experience.
